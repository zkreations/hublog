Welcome to Hublog! This theme was created to celebrate text-first publishing on the static web.

### Why Hublog?

Many modern web themes have grown increasingly complex, relying on intricate toolchains, client-side JavaScript libraries, and heavyweight styling frameworks. Hublog returns to the essence of static blogging:

- **Speed:** Instant page loads with no runtime execution overhead.
- **Simplicity:** Understandable templates that teach standard Hugo conventions.
- **Longevity:** Plain HTML and CSS that will render accurately for decades to come.

Feel free to browse around the demonstration site or explore the source templates to see how each page is structured.
