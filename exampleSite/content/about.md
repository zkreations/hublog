Hublog was created to provide a dependable, fast reading environment for blogs and to serve as a clear reference for learning Hugo.

### Core Principles

- **Zero dependencies:** No Sass, npm, or PostCSS build steps.
- **Zero JavaScript:** Pure HTML and CSS for lightning-fast delivery.
- **Semantic & Accessible:** Built from the ground up for assistive technology and clean hierarchy.
- **Standard Hugo:** Compatible with standard Hugo releases out of the box.
